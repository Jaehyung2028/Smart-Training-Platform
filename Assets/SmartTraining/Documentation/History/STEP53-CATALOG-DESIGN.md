# 콘텐츠 로비 목록 디자인

## 변경 위치와 함수

- `LobbyUI.prefab`의 `Lobby Browser Panel` : 기존 세로 스크롤 목록을 밝은 카드 형태로 변경했습니다. 상단 새로고침·알림 연결·로그아웃은 보조색, 하단 입장은 강조색을 사용합니다.
- `LobbyCardView.Render()` : 서버에서 받은 로비 이름, 사용자 수, 입장 대기 수, 방 수, 운영 상태를 각 텍스트에 표시합니다. 선택한 로비에는 강조 테두리·왼쪽 선·‘선택됨’ 문구를 표시합니다. 일반 마우스 포커스와 실제 로비 선택을 구분합니다.
- `LobbyUguiView.UpdateRows()` : 기존 목록 조회와 자동 갱신 경로에서 카드 정보를 전달합니다. 카드 컴포넌트가 없는 기존 프리팹도 기존 텍스트 표시로 동작합니다.
- `LobbyUguiView.Refresh()` : 다른 로비를 선택하면 상세 안내 스크롤을 맨 위로 이동합니다. 같은 로비의 인원이 갱신될 때는 사용자의 상세 스크롤 위치를 강제로 초기화하지 않습니다.
- `UguiCatalogDesigner.Apply()` : `DefaultUguiTheme`를 목록 버튼·카드·선택 강조에 적용합니다. `LobbyUguiBuilder.EnsureAssets()`로 새 프리팹을 생성할 때도 같은 디자인을 적용합니다.

운영 상태는 문구와 색상으로 함께 구분합니다. 입장 가능은 초록색, 종료 예정은 갈색, 점검 중은 빨간색입니다. 서버의 기존 입장 제한과 자동 갱신 기능은 유지합니다. 카드를 클릭하는 것만으로는 입장하지 않습니다.

카드 아래 `Selected Lobby Details`는 긴 점검 사유나 종료 안내를 읽을 수 있도록 별도 세로 스크롤을 사용합니다. 안내 길이 때문에 카드 목록이나 입장 버튼이 화면 밖으로 밀리지 않도록 했습니다.

## 직접 확인

1. 로그인하면 catalog.json의 로비 세 개가 카드로 표시되는지 확인합니다.
2. 카드를 바꿔 선택하면 강조 표시와 아래 상세 정보가 함께 바뀌는지 확인합니다.
3. 운영 페이지에서 점검·종료 예정을 변경하여 상태 문구와 입장 버튼이 자동 반영되는지 확인합니다.
4. 목록과 긴 상세 안내는 각각 해당 영역 위에서 스크롤할 수 있습니다.
5. ‘선택한 로비에 입장’으로 기존 로비 내부 화면에 이동하는지 확인합니다.

테마 재적용 메뉴는 `Smart Training → UI → Apply Lobby Catalog Theme`입니다. 이 메뉴는 프리팹의 목록 스타일 속성을 다시 적용하므로 개별 디자인을 수정했다면 해당 속성 변경을 확인한 뒤 사용합니다. 로그인 화면과 같은 테마 에셋을 사용하며 실행 중에 디자인을 다시 생성하지 않습니다.
