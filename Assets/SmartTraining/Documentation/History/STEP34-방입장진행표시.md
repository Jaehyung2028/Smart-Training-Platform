# 방 입장 진행 표시

## 변경
- `ApiLobbyScreen.RoomConnection.cs`의 `JoinRoom()`은 진행 표시를 시작하고 종료 시 해제합니다.
- `JoinRoomCore()`에서 접속 예약·방 서버 준비, Netcode 연결, 서버 승인 확인, 내 참가자 정보 준비 순서로 안내합니다.
- `DrawRoomJoinProgress()`는 입장 중 진행 화면을 표시합니다. 접속 확인 전에는 방 관리 화면을 표시하지 않습니다.
- 예약 실패나 접속 실패 시 기존 접속 정리·오류 안내를 유지합니다.
- `ApiLobbyScreen.OnGUI()`에서 진행 화면을 우선 표시하고, `ClearView()`는 세션 종료·화면 초기화 시 진행 표시를 지웁니다.

## 확인 방법
1. 서버를 실행하고 Unity에서 로그인한 뒤 방에 참가합니다.
2. 입장 중 단계 안내가 나타나고, 서버 승인과 참가자 생성이 완료되면 기존 방 화면이 나타나는지 확인합니다.
3. 비밀번호를 틀리게 입력하면 진행 화면이 사라지고 오류가 표시되는지 확인합니다.
4. 비밀번호를 수정하고 다시 참가할 수 있는지 확인합니다.

단계가 빠르게 완료되면 중간 안내는 짧게 보일 수 있습니다. 표시를 위해 접속을 지연시키지는 않습니다.
