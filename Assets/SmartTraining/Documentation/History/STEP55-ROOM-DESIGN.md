# 방 내부 공통 디자인

로그인 → 콘텐츠 로비 목록 → 로비 내부에 이어 방 내부까지 공통 테마를 적용했습니다.

## 변경 위치와 함수

- `RoomUI.prefab` : 상단 제목, 참가자·채팅·알림 목록, 준비·시작·설정 버튼과 입력칸의 색상·테두리·여백을 맞췄습니다. 방장 설정·관리 확인·위치 창도 같은 테마를 사용합니다.
- `RoomParticipantCard.RenderRoom()` : 역할(나·방장·참가자)과 준비 상태를 별도 줄에 표시합니다. 이름·연결 상태·지연·위치 정보는 아래에서 확인할 수 있습니다. 본인 카드의 테두리도 강조합니다.
- `RoomParticipantCard.RenderLobby()` : ‘현재 로비’ 목록에서는 기존 로비 참가자 정보를 표시하며 방 준비 상태 줄은 숨깁니다.
- `RoomUguiView.UpdateParticipants()` : 현재 방과 로비 목록에 맞는 참가자 카드 표시를 갱신합니다. 기존 ‘방장 위임·강퇴’ 버튼 경로와 권한 판단은 유지했습니다.
- `RoomUguiView.Refresh()` : 선택한 참가자 목록과 채팅 채널에 `UguiSelectionHighlight.SetSelected()`를 적용합니다. 버튼 입력 포커스와 별개로 실제 선택을 표시합니다.
- `UguiRoomDesigner.Apply()` : `DefaultUguiTheme`를 방 프리팹에 적용합니다. 준비·시작·저장·전송은 강조색, 방 닫기·강퇴는 옅은 빨간 배경과 진한 빨간 글자로 구분합니다.
- `RoomUguiBuilder.EnsureAssets()` : 신규 프리팹 생성 시에도 같은 테마를 적용합니다. 기존 프리팹을 삭제하거나 다시 생성할 필요는 없습니다.

## 직접 확인

1. 클라이언트 두 개로 같은 방에 들어가 본인·방장·참가자 표시를 확인합니다.
2. 준비와 준비 취소를 눌러 카드의 문구와 색상이 함께 바뀌는지 확인합니다.
3. ‘현재 방·현재 로비’ 및 ‘방 채팅·로비 채팅’을 전환해 선택 테두리가 이동하는지 확인합니다.
4. 방장 설정, 관리 확인, 위치 창의 입력과 닫기를 확인합니다.
5. 방장을 위임하면 역할 표시와 관리 버튼이 바뀌는지 확인합니다.
6. 작은 창에서도 참가자·채팅 목록과 설정 창을 스크롤할 수 있는지 확인합니다.

테마 재적용 메뉴는 `Smart Training → UI → Apply Room Theme`입니다. 이 메뉴는 프리팹의 테마 지정 색상·텍스트 스타일·목록 여백을 다시 적용하므로 개별 디자인을 수정했다면 해당 속성 변경을 확인한 뒤 사용합니다. 실제 실행 중에는 에디터에서 수정한 디자인을 자동으로 덮어쓰지 않습니다.
