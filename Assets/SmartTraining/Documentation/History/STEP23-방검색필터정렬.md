# STEP23: 방 검색·필터·정렬

## 변경 함수
- `RoomBrowser.Apply`: 방 이름 검색, 입장 가능 여부, 공개·비밀번호 방 필터를 함께 적용하고 정렬합니다. 서버에서 받은 원본 배열은 변경하지 않습니다.
- `RoomBrowser.CanJoin`: 빈자리, 잠금, 진행 상태 및 서버 종료 상태를 확인합니다. 전용 서버가 아직 없는 방도 입장 요청으로 시작할 수 있으므로 표시합니다.
- `ApiLobbyScreen.DrawRoomBrowser` / `GetDisplayedRooms`: 검색·필터·정렬 컨트롤과 표시 목록을 연결합니다.
- `ApiLobbyScreen.ResetRoomBrowser`: 검색·필터 초기화 버튼과 로그아웃 시 조건을 초기화합니다.

## 사용 방법
1. Unity 플레이를 다시 시작하고 로비를 선택합니다.
2. 방 이름 검색에 일부 이름을 입력합니다. 한글을 지원하며 영문 대소문자는 구분하지 않습니다. 검색어 앞뒤 공백은 제외합니다.
3. **입장 가능한 방만 보기**를 켜면 만석·잠금·진행 중·종료 중인 방은 제외합니다. 비밀번호 방은 비밀번호를 입력하면 입장할 수 있으므로 이 필터에서도 표시할 수 있습니다.
4. **전체 / 공개 방 / 비밀번호 방** 중 선택합니다.
5. **최근 생성순 / 빈자리 많은 순** 중 선택합니다. 빈자리는 접속 인원뿐 아니라 예약 인원도 반영합니다. 빈자리가 같으면 최근 생성된 방을 먼저 표시합니다.
6. 다른 클라이언트에서 방 이름·잠금 등을 변경합니다. 자동 갱신 시 기존 조건이 유지되며 조건에 맞는 방만 표시해야 합니다.
7. **검색·필터 초기화**로 전체 목록으로 돌아옵니다.

표시 개수와 전체 방 개수를 함께 보여줍니다. 조건에 맞는 방이 없으면 별도 안내를 표시합니다. 선택한 방이 검색 조건에서 사라지면 선택과 입장 비밀번호 입력도 비웁니다. 조건은 현재 플레이 중 로비 이동·목록 갱신에도 유지하며 로그아웃하면 초기화합니다. 다음 플레이까지 저장하지는 않습니다.

서버 API는 변경하지 않았습니다. 참가 버튼을 누르면 서버가 실제 입장 가능 여부를 다시 검사합니다.

## 검증
한글·영문 검색과 조건 조합, 예약으로 인한 만석 제외, 실행 전 방 표시, 정렬 및 원본 목록 보존을 검증합니다. 실제 Unity 통합 검증은 다른 참가자의 방 이름 변경·잠금·잠금 해제가 필터 결과에 반영되고, 알림 재접속 후 검색·정렬 조건도 유지되는지 확인합니다.
