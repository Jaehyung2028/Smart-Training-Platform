# STEP31 — 방 관리 실행 확인

방장 위임, 참가자 강퇴, 방 닫기 버튼을 누르면 먼저 화면 상단에 대상과 결과를 확인하는 영역이 열립니다.
확인 후 실행을 눌러야 서버에 요청하며 취소하면 서버 상태를 바꾸지 않습니다.
강퇴는 현재 연결을 끊는 기능이며 영구 차단은 아닙니다.

ApiLobbyScreen.RequestRoomAction()은 현재 방장만 확인 요청을 만들도록 합니다.
ValidateRoomAction()은 현재 로그인, 방, 네트워크 연결, 방장 권한과 대상의 접속 식별자를 다시 검사합니다.
확인 대기 중 대상이 퇴장하거나 재접속해 연결 식별자가 바뀌면 이전 요청을 취소합니다.
ConfirmRoomAction()은 요청을 먼저 비우고 기존 서버 API를 호출해 반복 클릭을 막습니다.
서버의 권한 검증은 그대로 적용됩니다. 확인 직후 상태가 바뀌어도 서버가 최종 권한과 대상을 검사합니다.

## 확인 방법
1. Unity 플레이를 다시 시작하고 새 클라이언트 빌드와 같은 방에 입장합니다.
2. 방장이 참가자 강퇴를 선택하면 바로 연결이 끊기지 않고 확인 영역이 열리는지 확인합니다.
3. 취소하면 모두 방에 남아 있는지 확인합니다.
4. 다시 강퇴를 선택하고 확인 후 실행하면 대상이 로비로 이동하는지 확인합니다.
5. 방장 넘기기와 방 닫기도 같은 확인 과정을 거치는지 확인합니다.
6. 강퇴 확인을 열어둔 상태에서 대상이 방을 나가면 요청이 자동 취소되는지 확인합니다.

현재 선택한 요청은 화면에만 유지하며 세션 종료, 로그아웃, 방 퇴장 시 정리합니다.
