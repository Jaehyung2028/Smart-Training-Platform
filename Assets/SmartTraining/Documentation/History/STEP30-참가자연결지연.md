# STEP30 — 방 참가자 연결 지연 표시

Unity 방 서버가 각 참가자의 UnityTransport.GetCurrentRtt() 값을 약 1초마다 확인합니다.
RoomPlayer.SetLatencyServer()가 서버 전용 NetworkVariable에 저장하고 모든 참가자가 측정 정보를 받습니다.
RoomMovementView.Draw()의 참가자 목록에 연결 지연(ms)을 표시합니다.

값은 참가자와 Unity 전용 방 서버 사이의 왕복 시간입니다.
측정 전에는 '측정 중'을 표시합니다. Transport의 0은 미측정 또는 유효한 연결 정보가 없을 수 있어 기존 값을 갱신하지 않습니다.
연결 종료 시 플레이어가 제거되며 새 플레이어는 다시 측정 중으로 시작합니다.

## 확인 방법
1. ASP.NET을 종료하고 다시 실행합니다. Unity 에디터도 플레이를 종료한 후 다시 시작합니다.
2. 에디터와 새 클라이언트 빌드에서 각각 로그인하고 같은 방에 접속합니다.
3. 참가자 목록에 두 참가자의 연결 지연이 ms로 표시되는지 확인합니다.
4. 방을 나갔다가 다시 입장하면 새 연결의 측정값이 표시되는지 확인합니다.

새 NetworkVariable이 추가되어 이전 클라이언트와 새 방 서버를 섞어 사용할 수 없습니다.
함께 갱신한 전용 방 서버와 클라이언트를 사용하세요.
