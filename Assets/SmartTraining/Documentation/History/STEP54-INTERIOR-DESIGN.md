# 로비 내부 공통 디자인

## 수정 위치

- `LobbyInteriorUI.prefab` : 방 목록·참가자·채팅 영역의 배경, 테두리, 목록 안쪽 여백을 정리했습니다. 검색·비밀번호·채팅 입력칸에도 테두리를 적용했습니다.
- `UguiInteriorDesigner.Apply()` : `DefaultUguiTheme`의 공통 색상을 로비 내부에 적용합니다. 새 방 만들기·입장·전송·방 생성·재접속은 강조색, 나머지 작업과 필터는 보조색을 사용합니다. 생성 창과 입장 진행 창에도 같은 색상을 적용했습니다.
- `UguiSelectionHighlight.SetSelected()` : 방 목록에서 선택한 항목의 테두리 색과 두께를 변경합니다.
- `LobbyInteriorUguiView.UpdateRooms()` : 목록 갱신 시 현재 선택한 방의 강조 표시를 반영합니다. 마우스가 다른 버튼으로 이동해도 방 선택은 유지됩니다. 기존 ‘●’ 선택 표시와 방 상태 문구도 유지합니다.
- `LobbyInteriorUguiBuilder.EnsureAssets()` : 프리팹 신규 생성 시 같은 디자인을 적용합니다. 기존 프리팹은 다시 생성하지 않습니다.

기존 방 생성·검색·필터·비밀번호·재접속·참가자 보기·채팅·입장 취소 기능은 그대로 사용합니다. 이번 작업은 로비 내부 화면이며 실제 방 내부 디자인은 다음 작업 대상입니다.

## Unity에서 확인

1. 로그인 → 콘텐츠 로비 선택 → 입장으로 로비 내부 화면을 엽니다.
2. 방을 만들고 선택하면 테두리와 아래 상세 정보가 선택한 방에 맞는지 확인합니다.
3. 검색·필터를 바꾸고 참가자 목록과 채팅을 사용합니다.
4. 새 방 만들기 창에서 입력·닫기·생성을 확인합니다.
5. 작은 창이나 넓고 낮은 창에서도 목록 스크롤과 입장·퇴장 버튼을 사용할 수 있는지 확인합니다.

디자인 재적용 메뉴는 `Smart Training → UI → Apply Lobby Interior Theme`입니다. 이 메뉴는 해당 프리팹의 테마 지정 스타일 속성을 다시 적용합니다. 개별적으로 디자인을 변경했다면 해당 속성 변경을 확인한 뒤 사용해주세요. 실행 중에는 에디터 디자인을 자동으로 덮어쓰지 않습니다.
