# 로그인 화면과 공통 UI 스타일

로그인 화면을 첫 디자인 기준으로 적용했습니다. 다른 화면의 본문 디자인은 이후 같은 테마를 사용해 순서대로 작업합니다.

## 변경 위치

- `Resources/SmartTraining/LobbyUI.prefab` : `Login Panel` 안에 `Login Introduction`과 `Login Form`을 배치했습니다. 왼쪽은 안내, 오른쪽은 기존 서버 주소·닉네임 입력 및 버튼입니다. 기존 입력 컴포넌트와 버튼 참조는 유지했습니다.
- `Scripts/UI/Common/UguiTheme.cs`와 `Resources/SmartTraining/DefaultUguiTheme.asset` : 배경·본문·보조 글자·강조 색상, 기본 글자 크기와 컨트롤 높이를 관리합니다. 현재 기준은 본문 16, 컨트롤 높이 44입니다.
- `Editor/UguiLoginDesigner.Apply()` : 저장된 테마를 로그인 프리팹에 적용합니다. 실행 중에 디자인을 강제로 덮어쓰지 않습니다.
- `Editor/LobbyUguiBuilder.EnsureAssets()` : 프리팹을 신규 생성할 때도 같은 로그인 디자인을 적용합니다. 기존 프리팹은 새로 만들지 않습니다.

로그인 버튼은 강조색, 주소 저장·초기화·서버 연결 확인은 보조색을 사용합니다. 입력란은 배경과 외곽선으로 구분하며 버튼의 마우스 오버·선택·눌림·비활성 상태를 지정했습니다. 공유 영역인 상단 제목과 연결·상태 문구도 색상과 글자 크기를 맞췄습니다.

## 직접 수정

1. Unity에서 `Smart Training → UI → Scene UI Editor`의 로그인 미리보기를 선택합니다.
2. Hierarchy에서 `Login Introduction`과 `Login Form`을 선택하여 배치와 문구를 수정합니다.
3. 공통 색상은 `DefaultUguiTheme` 에셋을 선택해 Inspector에서 변경합니다.
4. 테마 값을 로그인 화면에 다시 적용할 때만 `Smart Training → UI → Apply Login Theme`를 실행합니다. 이 메뉴는 로그인 입력란·버튼의 테마 지정 색상과 크기를 다시 적용합니다. 개별적으로 다듬은 해당 속성이 있으면 실행 전에 확인해주세요.

테마 에셋은 아직 나머지 화면의 모든 컨트롤에 적용하지 않았습니다. 로비 목록·로비 내부·방 내부는 다음 디자인 작업 대상입니다.

## 확인 방법

Play에서 서버 주소와 닉네임을 입력해 로그인하고, 로그아웃해 입력 화면으로 돌아옵니다. `800×600`, `1280×720`, `1600×600` 비율에서 폼·버튼·상태 문구가 겹치지 않는지 확인합니다. 주소 저장·초기화와 서버 연결 확인도 기존과 동일하게 사용할 수 있습니다.
