# 다른 PC에서 Unity 클라이언트 실행하기

1. 서버 PC에서 ASP.NET을 실행합니다. 서버 콘솔의 `[접속] 다른 PC에서 입력할 API 주소 후보`를 확인합니다.
2. `Builds/TestBundles/날짜-고유번호/Client` 전체 폴더를 다른 PC에 복사합니다. `_Data`와 DLL을 포함합니다.
3. 다른 PC의 브라우저에서 `http://서버PC의IP:5229/api/health`에 접속합니다. `status: ok`가 표시되면 API 주소까지 연결된 것입니다.
4. 클라이언트 로그인 화면에 `http://서버PC의IP:5229`를 입력하고 서버 연결 확인 → 닉네임 로그인 → 콘텐츠 로비 → 방 입장 순서로 진행합니다.

다른 PC에서 `localhost`나 `127.0.0.1`을 입력하면 서버 PC가 아닌 그 PC 자신을 가리킵니다. API 포트를 바꿨다면 입력 주소의 포트도 맞춰주세요.

## 로비는 보이는데 방 입장에 실패할 때

- 서버의 `Room:AdvertisedAddress`가 클라이언트에서 접근 가능한 서버 PC의 IP인지 확인합니다. 어댑터가 여러 개면 서버 콘솔의 후보 중 클라이언트와 같은 네트워크의 주소를 지정합니다.
- API TCP 포트와 Unity 전용 서버 프로그램의 UDP 수신을 구분합니다. `/api/health` 성공만으로 UDP 접속까지 확인된 것은 아닙니다.
- Unity 전용 서버 실행 파일이 폴더 전체와 함께 배치되어 있는지 확인합니다. API 공통 실행 경로와 `catalog.json`의 로비별 실행 경로도 확인합니다.

방화벽 수신 규칙과 읽기 전용 진단 도구 사용법은 서버 저장소의 `Smart Training Server/LAN-접속안내.md`에 있습니다. 두 PC에서 같은 방에 접속해 준비·시작·채팅·이동과 강제 종료 후 재접속을 확인해주세요. 같은 PC의 LAN 주소를 사용한 확인은 실제 다른 PC에서의 접속 확인을 대신하지 않습니다.
