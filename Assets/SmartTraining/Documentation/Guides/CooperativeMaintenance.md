# 협동 실습 콘텐츠

## 콘텐츠 구성

| 교육과정 | 콘텐츠 | 권장 인원·역할 |
|---|---|---|
| 장비 기초 교육 | 협동 장비 접점 정비 (2인) | 2인: 점검·정비 |
| 작업 안전 교육 | 협동 방호 덮개 복구 (2인) | 2인: 점검·정비 |
| 비상 대응 교육 | 협동 비상 유도등 복구 (4인) | 4인: 점검·정비·안전 확인·진행 |

2인·4인은 역할을 나눠 맡는 권장 편성입니다. 접속 인원 제한이나 시작에 필요한 최소 인원이 아닙니다. 인원이 적으면 한 사람이 비어 있는 여러 역할을 겸임할 수 있습니다. 예를 들어 4인 권장 콘텐츠를 혼자 진행할 때도 단계에 필요한 역할을 순서대로 추가하면 끝까지 수행할 수 있습니다.

## 역할 선택과 공유

- 우측 하단 기능 메뉴에서 빈 역할을 선택하면 기존 역할을 유지하면서 추가로 맡습니다.
- 역할당 담당자는 한 명입니다. 다른 사람이 맡은 역할은 선택할 수 없습니다.
- 한 역할만 배정되어 있어도 그 역할의 단계는 수행할 수 있습니다. 모든 역할이 채워질 때까지 기다리지 않습니다.
- 진행 중에도 빈 역할을 추가할 수 있습니다. 본인이 공구 작업 중이면 완료하거나 취소한 뒤 추가합니다.
- 메뉴에 담당자 이름을 표시하고, 이미 배정된 역할 버튼은 비활성화합니다.
- 머리 위 이름표에는 겸임한 역할을 모두 표시합니다. 참가자 목록에는 이름·방장·연결 상태만 표시합니다.
- 퇴장하면 보유한 모든 역할을 반환합니다. 작업자가 퇴장하면 진행하던 작업도 취소합니다.
- 방장의 다시 실습하기는 진행·결과·역할·장비 표시를 초기화합니다.

권한은 클라이언트 표시뿐 아니라 Unity 서버에서도 검사합니다. 역할 선택·작업 요청의 실습 버전을 확인해 재시작 전의 요청을 거절하며, 현재 역할을 가진 실제 참가자만 해당 단계를 수행할 수 있습니다.

## 단계별 진행

### 장비 기초: 협동 장비 접점 정비

1. 점검: FAULT 표시등 확인
2. 정비: 스패너로 COVER BOLT 풀기
3. 정비: CONTACT 클릭으로 접점 교체 (공구 불필요)
4. 정비: 스패너로 볼트 체결
5. 점검: TEST 버튼으로 작동 확인

### 작업 안전: 협동 방호 덮개 복구

1. 점검: WARN 표시등 확인
2. 정비: 스패너로 BOLT 풀기
3. 정비: GUARD 클릭으로 덮개 닫기 (공구 불필요)
4. 정비: 스패너로 볼트 고정
5. 점검: TEST 버튼으로 덮개 확인 스위치 점검

### 비상 대응: 협동 비상 유도등 복구

1. 진행: 아래쪽 CHECK 판에서 복구 순서 확인
2. 안전 확인: 아래쪽 POWER 스위치에서 훈련용 전원 차단 확인
3. 점검: EXIT LIGHT 상태 확인
4. 정비: 드라이버로 SCREW 풀기
5. 정비: BATTERY 클릭으로 배터리 교체 (공구 불필요)
6. 정비: 드라이버로 나사 체결
7. 점검: TEST 버튼으로 점등 확인

덮개·접점·배터리 교체와 마지막 초록 표시등 변화는 승인된 공동 단계에 맞춰 모두에게 표시됩니다. 완료 결과에는 실제 단계 수행자가 기록됩니다.

## 편집 위치

| 콘텐츠 | 데이터·프리팹 폴더 | Addressables 주소 |
|---|---|---|
| 장비 접점 정비 | `Content/Scenarios/CooperativeMaintenance` | `content/scenario/cooperative-maintenance` |
| 방호 덮개 복구 | `Content/Scenarios/CooperativeSafety` | `content/scenario/cooperative-safety` |
| 비상 유도등 복구 | `Content/Scenarios/CooperativeEmergency` | `content/scenario/cooperative-emergency` |

폴더는 `Assets/SmartTraining` 아래입니다. 단계는 `ScenarioDefinition.Step.RequiredRole`에서 단일 역할을 설정합니다. 콘텐츠가 사용하는 역할 목록은 실제 단계의 역할에서 구하므로, 두 역할 콘텐츠에는 네 역할 버튼이 모두 나타나지 않습니다.

- 최초 생성·등록: `CooperativeMaintenanceBuilder.Prepare()`, `CooperativeCourseBuilder.Prepare()`
- 공용 생성 함수: `CooperativeSampleUtility`
- 배정·겸임·단계 규칙: `ScenarioProgress.TrySelectRole()`, `GetRoles()`, `TryInteract()`
- 서버 승인·공유: `SharedScenario.SelectRoleRpc()`와 역할 NetworkList
- 역할 메뉴: `ScenarioRoleMenu`
- 단계별 모형 교체: `ScenarioStageVisuals`

이미 생성된 파일은 일반 빌드에서 덮어쓰지 않습니다. 가상 장비와 기본 도형으로 구성한 협동 기능 샘플이며 실제 장비의 정비·전원 차단·배터리 교체 지침이 아닙니다.
