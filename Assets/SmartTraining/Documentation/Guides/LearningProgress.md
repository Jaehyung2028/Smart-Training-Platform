# 학습 진행과 완료 표시

콘텐츠 시작마다 참가자의 실행 번호를 새로 부여합니다. 이전 실행의 늦은 보고는 반영하지 않습니다.
진행률은 각 RoomPlayer의 TrainingProgress 컴포넌트에 저장하고 Netcode NetworkVariable로 공유합니다.
콘텐츠 화면은 본인의 진행을, 대기실 참가자 카드는 각 참가자의 결과를 표시합니다.

## 완료 기준

- 영상: VideoWatchCoverage가 실제 로컬 재생 구간의 합집합을 계산합니다. 반복 재생은 중복 집계하지 않고 큰 구간 이동은 시청으로 인정하지 않습니다. 전체 구간을 시청하고 끝에 도달해야 완료됩니다. 디코딩 시각 오차를 고려해 최대 0.25초의 허용 오차가 있습니다.
- 모델: ModelPartInfo의 Required For Completion을 켠 부품이 관찰 대상입니다. 각 부품을 직접 클릭하거나 트리 목록에서 선택합니다. 부모 선택으로 자식까지 확인 처리하지 않고 공유 분해 애니메이션의 자동 강조도 포함하지 않습니다. 공구나 모델 회전 권한과 별개로 개인에게 기록합니다.
- 시나리오: 기존 SharedScenario 서버 판정의 완료 단계 비율을 모든 참가자에게 공동 결과로 반영합니다. 방장이 실습을 초기화하면 공동 결과도 초기화합니다.

## 보관과 보고 범위

대기 복귀에서는 결과를 유지하고 방장이 다시 시작하면 초기화합니다. 방 퇴장 시 해당 플레이어가 제거되므로 개인 결과가 사라집니다. 방 서버 종료나 재접속 이후 결과를 복원하는 영구 기록은 아직 없습니다.
영상과 모델 관찰은 개인 클라이언트가 계산해 보고하는 진행 표시입니다. 서버는 소유자·현재 실행 번호·진행 상태·0~100 범위를 검사하지만 실제 화면 시청을 증명하는 수료 인증이나 부정행위 방지 기능은 아닙니다. 공동 실습은 서버가 직접 완료를 판정합니다.
개인 보고는 진행 변화가 있을 때 최대 초당 한 번이며 최종 완료는 즉시 전송합니다.

## 수정 위치

- Gameplay/Progress/TrainingProgress.cs: 실행 번호·서버 기록·진행 공유
- Domain/Learning/VideoWatchCoverage.cs: 중복·구간 이동을 제외하는 시청 계산
- Gameplay/Video/VideoContentPlayer.cs: 로컬 영상 재생 상태 전달
- Gameplay/Model/ModelViewer.cs: 직접 선택한 부품 확인
- UI/Content/ContentHudController.cs: 콘텐츠 진행 표시
- UI/Views/RoomParticipantCard.cs: 대기실 결과 표시
